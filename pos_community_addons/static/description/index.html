Restaurant POS customizations: kitchen receipts, floor plan styling, streamlined UI

Author: Efstathios Voulgaris

Category: Point of Sale

What it does

Extends the pos_restaurant module for café and restaurant use. Focuses on kitchen workflow, floor plan visibility, and a stripped-down UI suited for quick table service.

Features

  • Kitchen receipts — custom barista/preparation ticket printed via Epson ePOS on every order send. Includes table reference, employee, timestamp, item attributes, and notes. Dynamic company name from Odoo config.
  • Auto receipt after payment — respects the built-in Automatic Receipt Printing setting (iface_print_auto). Navigates straight back to the floor plan after payment.
  • Table number on payment screen — displays the current table prominently above the total on the payment screen.
  • Occupied table timer — shows elapsed time since first order on each occupied table (green <30 min, yellow 30–60 min, red >60 min). No background polling.
  • Occupied table highlighting — red border and glow on occupied tables; table color used as background.
  • Item count badge — shopping basket icon with total item count on each occupied table.
  • Streamlined UI — Customer and Course buttons removed from both mobile and desktop order screens. Send button item-count label removed to prevent mobile layout issues.
  • Pay button visibility — Pay button shown only when there are unsent items and the order is non-empty.

Compatibility

Odoo 19.0. Requires the official pos_restaurant module.
